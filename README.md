# GNS COMPANY

GNS COMPANY, Bootstrap kullanılarak hazırlanmış statik bir şirket/portföy web sitesi
örneğidir. Projede ana sayfa, hakkımızda, ekip, galeri ve iletişim bölümleri ile
ekip üyeleri için detay sayfası bulunur.

## Kullanılan teknolojiler

- HTML5
- CSS3
- JavaScript
- [Bootstrap 5](https://getbootstrap.com/)
- Google Fonts

## Projeyi çalıştırma

Projenin çalışması için ek bir paket kurulmasına gerek yoktur.

1. Bu repository'yi bilgisayarınıza indirin veya klonlayın.
2. `index.html` dosyasını bir tarayıcıda açın.

Geliştirme sırasında daha iyi bir deneyim için projeyi VS Code'da açıp Live Server
gibi bir yerel geliştirme sunucusuyla çalıştırabilirsiniz.

## Dosya yapısı

```text
.
├── index.html       # Ana sayfa
├── detay.html       # Ekip üyesi detay sayfası
├── JS/
│   └── app.js       # Ekip üyesi verileri ve sayfa davranışları
├── css/
│   └── style.css    # Site stilleri
├── img/             # Galeri ve ekip görselleri
└── Proje07_PortfolioApp.slnx
```

## Notlar

- Ekip bilgileri sentetik ve kurgu amaçlıdır.
- `img/` klasöründeki görseller public kullanım öncesinde ilgili kaynakların
  kullanım şartları ve lisansları kontrol edilerek kullanılmalıdır.
- Bu proje içinde sunucu tarafı kodu, veritabanı veya API anahtarı bulunmaz.

Bu repository için henüz bir lisans dosyası eklenmemiştir. Lisans eklenene kadar
